About Me.

I'm Aditya Tiwari, a Computer Science student at SOA, ITER in Bhubaneswar, Odisha. I'm drawn to understanding the bedrock of computer systems: how network packets travel, how operating systems manage hardware interrupts, how native C/C++ audio pipelines minimize latency, and how machine learning models actually generalize.

Rather than assembling black-box npm packages, I take joy in writing software where performance, predictability, and memory semantics matter.
