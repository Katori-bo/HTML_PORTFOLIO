# Aditya Tiwari — Personal Portfolio & Systems Showcase

An editorial, systems-focused personal portfolio and digital garden. Built with vanilla HTML5, CSS3, and high-performance Canvas engines—zero heavy UI frameworks, pure web craft.

---

## ✦ Key Features

- **Signature Voxel Transition Engine**:
  - A custom 3-layer chunky voxel frontier inspired by Transform9.
  - Symmetrical two-way scroll (Hero Dark `#090c0a` ↔ Electric Blue & Lime Voxels ↔ Editorial Cream `#faf6ee`).
  - Architectural scale (massive 240px blocks on desktop) with zero border grid lines.
  - Interactive mouse hover reactions.
- **Dark Monaspace Hero**:
  - Terminal-inspired header and canvas grid with ambient cursor illumination.
- **Editorial Workshop Section**:
  - Crisp typography, system engineering pillars, and ingredient tags.
- **Interactive Projects Showcase (`projects.html`)**:
  - Tag-based filtering, architecture diagrams, benchmark comparisons, and live links.
- **The Arcade (`arcade.html`)**:
  - Frosted glass aesthetic with illuminated responsive grid squares, retro games, and interactive experiments.
- **Media Shelf & Library (`library.html`)**:
  - Digital bookshelf, paper shelf, and curated research readings.
- **Lightweight & Fast**:
  - Vanilla HTML, CSS, and modern JavaScript.
  - Zero npm dependencies, 100% static hosting compatible.

## ✦ Local Development

No build step or package manager required. Run any static HTTP server:

### Using Python:
```bash
python3 -m http.server 8000
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.

### Using Node.js (`npx serve`):
```bash
npx serve .
```

### Using VS Code Live Server:
Right-click `index.html` and select **"Open with Live Server"**.

## ✦ Tech Stack

- **Markup**: Semantic HTML5
- **Styling**: Modern CSS3 (Custom Properties, Flexbox, CSS Grid, Sticky Positioning)
